장부는 내 곁에

개인정보 처리방침

포켓 위시는 장부를 기기에 저장하며 오프라인으로 기록할 수 있는 개인 가계부 앱입니다. 회원가입이 필요 없고 장부 내용은 기기에 보관됩니다. 앱에는 Google 광고 및 동의 관리 SDK가 포함되어 있으며, 해당 SDK의 네트워크 데이터 처리는 장부 데이터와 구분하여 설명합니다.

광고 및 동의 관리가 포함된 업데이트에 적용 · 업데이트: 2026년 10월 17일

简体中文EnglishTiếng Việt한국어日本語
기기 내 데이터광고와 동의 관리권한과 시스템 서비스백업과 직접 공유열람과 삭제웹사이트와 피드백변경과 연락

백업 파일과 비밀번호를 직접 안전하게 보관하세요. 앱은 자동 클라우드 백업이나 기기 간 동기화를 제공하지 않습니다. 개발자에게는 장부 사본이 없으며 잊은 백업 비밀번호를 복구할 수 없습니다.

01. 장부의 기기 내 보관

사용자가 만든 장부, 구성원 표시, 계좌, 분류, 수입·지출 내역, 메모, 태그, 예산, 저축 목표, 배정·인출 기록, 반복 계획, 자주 쓰는 거래 양식, 확인한 영수증 인식 문자와 설정은 앱의 기기 내 디렉터리에 저장됩니다. 이 데이터는 내역 표시, 잔액과 계획 진행 상황 계산, 통계 생성, 요청한 가져오기·내보내기에 사용됩니다.

앱에는 개발자가 운영하는 장부 서버나 로그인 계정이 없습니다. 은행 또는 제3자 결제 거래를 자동으로 읽지 않으며 장부 내용을 개발자나 광고 서비스로 보내지 않습니다. 광고와 동의 관리를 위해 Google Mobile Ads 및 User Messaging Platform(UMP) SDK를 사용하며 네트워크 처리는 다음 항목에서 설명합니다. 구성원 기능은 같은 기기에서 내역의 귀속을 표시하고 필터링하기 위한 것으로 온라인 공동 작업이 아닙니다.

기기 내 데이터 파일에는 iOS 파일 보호가 적용되며 시스템 자동 백업에서는 제외됩니다. 복원 전 보관하는 기기 내 스냅샷도 같은 파일 보호를 사용하며 마지막 복원을 되돌리는 데 쓰입니다. 별도로 내보낸 비밀번호 암호화 백업과는 다릅니다. 기기 보안은 운영체제, 기기 암호와 사용 환경에도 영향을 받습니다.

02. 광고 서비스와 개인정보 선택

앱은 Google AdMob(Google Mobile Ads SDK)을 통해 배너, 앱 실행 광고, 콘텐츠 전환 시 전면 광고, 사용자가 선택하는 보상 동영상을 제공합니다. UMP SDK는 해당 지역의 동의 선택을 수집·관리합니다. 동의 절차가 광고 요청을 허용한 후에만 광고 서비스를 초기화하고 광고를 요청합니다. 맞춤 설정이나 동의를 거부한 뒤 광고가 제공되는지는 지역 규칙, 선택 내용과 SDK 상태에 따라 달라지며 기기 내 가계부 이용에는 영향을 주지 않습니다.

Google 광고 서비스는 광고 제공·측정, 부정행위 방지와 서비스 유지를 위해 IP 주소, 기기 또는 광고 식별자, 광고 상호작용, 진단 및 성능 데이터를 처리할 수 있습니다. 구체적인 항목은 SDK, 기기 권한과 지역에 따라 달라집니다. 장부 금액, 수입·지출 기록, 구성원, 메모, 사진 및 백업 파일은 광고 서비스로 전송되지 않습니다. 별도의 광고 사용자 계정이나 개발자 장부 분석 서비스는 만들지 않습니다.

앱의 “내 정보 → 광고 개인정보 옵션”에서 사용 가능한 개인정보 양식을 다시 열 수 있습니다. 양식의 표시 여부와 선택지는 UMP 및 지역 요구사항에 따라 결정됩니다. 해당하는 경우 iOS 설정에서 시스템 권한을 관리할 수도 있습니다. 장부를 비워도 Google이 이미 처리한 데이터가 자동 삭제되거나 제3자 서비스에서 한 선택이 철회되지 않습니다. Google 개인정보처리방침과 Google 광고 기술 안내를 참고하세요.

보상 동영상은 전적으로 선택 사항입니다. SDK가 보상을 확인한 경우에만 기기에 장식용 감사 별 하나를 추가합니다. 시청을 완료하지 않거나 동영상을 이용할 수 없으면 지급하지 않습니다. 별은 현금 가치가 없으며 계좌 잔액, 예산, 저축 목표 또는 가계부 데이터를 바꾸지 않습니다. 동영상을 닫은 뒤에도 장부를 계속 사용할 수 있습니다.

03. 권한 및 시스템 서비스 사용

기능사용 시점과 처리 내용
영수증 사진사용자가 시스템 사진 선택기를 열고 사진을 고른 경우에만 해당 사진을 읽어 기기의 Apple Vision으로 문자를 인식합니다. 전체 사진 보관함을 스캔하거나 클라우드 인식을 사용하지 않으며 영수증 원본 사진을 저장하지 않습니다. 금액을 확인하고 내역을 저장하면 인식 문자가 내역과 함께 기기에 저장됩니다. 인식이 부정확할 수 있으니 저장 전에 확인하세요.
기기 인증앱 잠금을 켠 뒤 시스템이 기기 암호 또는 사용 가능한 생체 인증으로 확인합니다. 앱은 지문, 얼굴 템플릿 또는 기기 암호에 접근하거나 저장하지 않습니다. 백그라운드에서는 장부를 가리며 돌아오면 잠금 해제가 필요합니다.
알림일일 알림을 켤 때만 시스템 알림 권한을 요청합니다. 알림은 기기에 예약하며 개발자 원격 푸시 서비스를 사용하지 않고 거래 금액을 표시하지 않습니다. 알림을 거부해도 기록할 수 있습니다.
파일과 공유사용자가 가져오기, 내보내기 또는 복원을 시작할 때만 시스템 파일 선택기나 공유 시트로 선택한 파일을 처리합니다. 파일 서비스의 후속 처리는 해당 서비스에 따라 달라집니다.

앱에서 알림이나 앱 잠금을 끄고 iOS 설정에서 관련 시스템 권한을 관리할 수 있습니다. 사진 선택을 취소해도 거래가 만들어지지 않습니다. 앱은 연락처, 위치 또는 마이크 접근을 요청하지 않습니다.

04. 백업, 내보내기와 사용자가 시작한 공유

암호화 백업: 사용자가 직접 만들며 입력한 비밀번호로 PBKDF2 키 유도 및 AES-GCM 인증 암호화를 수행합니다. 비밀번호는 개발자 서버에 저장하지 않습니다. 신뢰하는 위치에 백업 파일을 보관하고 비밀번호는 별도로 안전하게 관리하세요. 비밀번호 분실, 기기 손상, 앱 삭제 또는 기기 분실 후 개발자는 백업하지 않은 데이터를 복원할 수 없습니다.

CSV 내보내기: CSV는 암호화되지 않은 일반 텍스트이며 금액, 계좌 이름, 구성원, 메모와 태그를 포함할 수 있습니다. 파일을 가진 사람이 내용을 읽을 수 있습니다. 공유 전에 내용과 수신자를 확인하고 CSV를 암호화 백업으로 취급하지 마세요.

시스템 파일 선택기에 본인의 iCloud Drive나 다른 클라우드 드라이브가 표시되거나 공유 시트에 제3자 앱이 포함될 수 있습니다. 해당 대상을 선택하면 서비스가 자체 개인정보 처리방침에 따라 파일을 업로드하거나 처리할 수 있습니다. 앱이 이 파일들을 자체적으로 업로드하거나 자동 동기화하지는 않습니다.

복원 시 파일 유효성을 먼저 확인하고 사용자 확인 후에만 기기 내 장부를 교체하며 되돌리기용 복원 전 스냅샷을 보관합니다. 중요한 데이터를 덮어쓰기 전에 작동을 확인한 백업을 별도로 보관하세요.

05. 열람, 수정과 삭제

앱에서 내역을 보고 수정하며 장부와 분류를 관리하고 기록을 내보내거나 암호화 백업을 만들 수 있습니다. 회계 연결 관계를 보존하기 위해 일부 삭제는 관련 내역을 먼저 처리하거나 목표에 배정한 금액을 인출해야 합니다.

“내 정보”의 전체 데이터 삭제는 확인 후 앱의 기기 내 장부와 설정을 삭제합니다. 파일 앱, 클라우드, 다른 앱으로 내보냈거나 다른 사람에게 공유한 사본은 함께 삭제되지 않습니다. 해당 위치에서 별도로 처리해야 합니다. 앱은 사진 보관함의 원본 사진을 삭제하지 않습니다.

개발자에게는 열람하거나 삭제할 장부 사본이 없습니다. 삭제를 요청하기 위해 공개 피드백 채널에 거래 내역, 신분증, 백업 파일이나 비밀번호를 보내지 마세요.

06. 웹사이트 및 공개 피드백은 별도의 이용 상황

이 소개 웹사이트는 GitHub Pages에서 호스팅됩니다. 웹사이트 자체는 분석 추적 스크립트, 광고, 제3자 글꼴, 외부 이미지 또는 CDN 의존성을 추가하지 않습니다. 테마 미리보기는 현재 페이지 안에서만 바뀌며 계정을 만들거나 장부 데이터를 저장하지 않습니다.

웹사이트 방문 시 GitHub는 호스팅 제공, 운영 및 보안을 위해 IP 주소, 요청 시각, 기기나 브라우저 정보 등의 일반 접속 로그를 처리할 수 있습니다. 구체적인 처리는 GitHub 개인정보처리방침을 따릅니다. 이는 오프라인 앱이 거래를 GitHub로 업로드한다는 뜻이 아닙니다.

지원 피드백은 GitHub Issues로 받습니다. 게시한 계정명, 문제 설명, 댓글과 첨부 파일은 공개될 수 있으며 개발자는 사용자가 제출한 내용을 볼 수 있습니다. 개인정보가 없는 재현 단계만 제공하세요. 실제 거래, 계좌 번호, 백업, 비밀번호 또는 가리지 않은 스크린샷을 올리지 마세요. GitHub 이용에는 GitHub의 약관과 개인정보 처리방침이 적용됩니다.

07. 방침 변경과 연락

앱의 데이터 처리 방식이 바뀌면 이 페이지의 내용과 날짜를 갱신하고 적절한 위치에 설명합니다. 이 방침은 적용되는 앱 버전과 이 웹사이트의 실제 동작을 설명합니다.

개인정보, 권한 또는 기기 내 데이터 작업에 관한 질문은 지원 페이지를 보거나 Jacky-LinPeng / wealth-ledger-pages의 공개 Issues를 통해 관리자에게 문의하세요. 공개 채널이므로 민감한 데이터를 포함하지 마세요.
