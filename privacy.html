隐私政策

Pocket Wishes - 存钱日记是一款本机离线的生活记账应用。无需注册；账本内容保存在本机。应用包含 Google 广告与同意管理 SDK，其网络数据处理与账本数据分别说明。

请自己保管备份文件和密码。应用不提供自动云备份或跨设备同步。开发者没有你的账本副本，也不能找回遗失的备份密码。

01. 账本如何保存在本机

你创建的账本、成员标签、账户、分类、收支流水、备注、标签、预算、存钱目标、存取记录、周期计划、常用账单、经你确认的票据识别文字和设置，保存在应用的本机目录内。这些数据用于显示账单、计算余额和计划进度、生成统计以及执行你要求的导入导出。

应用不设开发者账本服务器或登录账号，不自动读取银行或第三方支付交易，也不把账本内容提供给开发者或广告服务。应用集成 Google Mobile Ads 与 User Messaging Platform（UMP）SDK，用于提供广告及管理同意；相关网络处理见下节。家庭成员功能仅用于同一设备上的归属记录和筛选，不是联网协作。

本机数据文件使用 iOS 文件保护，并排除系统自动备份。恢复前保留的本机快照同样受本机文件保护，用于撤回上次恢复；它不等于你另行导出的密码加密备份。设备安全仍取决于系统、设备密码和使用环境。

02. 广告服务与隐私选择

应用使用 Google AdMob（Google Mobile Ads SDK）提供横幅、启动广告、内容过渡插页以及你主动选择的激励视频。UMP SDK 用于收集并管理适用地区的同意选择；只有同意流程允许请求广告后，应用才初始化广告服务并发起广告请求。拒绝个性化或不同意的后续广告可用性由地区规则、你的选择与 SDK 状态决定，不影响本机记账。

Google 广告服务可能处理 IP 地址、设备或广告标识符、广告互动、诊断及性能数据，以投放和衡量广告、防范欺诈并维护服务。具体项目取决于 SDK、设备授权和地区。账本金额、收支记录、成员、备注、照片及备份文件不会发送给广告服务。我们没有另建广告用户账号或开发者账本分析服务。

可在应用“我的 → 广告隐私选项”中重新打开可用的隐私表单；表单是否显示及可选内容由 UMP 和地区要求决定。适用时，系统授权也可在 iOS 设置中管理。清空账本不会自动删除 Google 已处理的数据，也不会撤销你在第三方服务中的选择。进一步了解 Google 隐私政策和 Google 广告技术说明。

激励视频完全自愿。只有 SDK 确认获得奖励时，应用才在本机增加一枚装饰感谢星章；观看未完成或不可用时不发放。星章无现金价值，不改变账户余额、预算、存钱目标或任何记账数据。关闭视频后可继续使用账本。

03. 权限和系统服务如何使用

功能何时使用、处理什么
票据照片仅在你主动打开系统照片选择器并选中图片后，读取该图片用于 Apple Vision 本机文字识别。不扫描整个照片图库，不调用云端识别。应用不保存原始票据图片；你核对金额并保存账单时，识别文字会随账单在本机保存。识别可能有误，请核对后再保存。
设备认证仅在你开启应用锁后，通过系统的设备密码或可用生物识别进行验证。应用不接触、不存储指纹、面部模板或设备密码。回到后台时遮挡账本，重新进入需要解锁。
通知你开启每日提醒时才请求系统通知权限。提醒由设备本地安排，不使用开发者远程推送服务，通知内容不展示账单金额。拒绝通知权限不影响记账。
文件与分享只有你主动导入、导出或恢复时，使用系统文件选择器或分享面板处理你选择的文件。文件服务的后续行为由所选服务决定。

你可以在应用设置中关闭提醒或应用锁，并在 iOS 设置中管理相关系统权限。取消照片选择不会写入账单。应用不要求通讯录、定位或麦克风访问。

04. 备份、导出与主动分享

加密备份：由你主动创建，并使用你填写的密码进行 PBKDF2 密钥派生与 AES-GCM 认证加密。密码不保存到开发者服务器。请将备份文件存放在你信任的位置，单独妥善保管密码。密码遗失、设备损坏、应用卸载或设备丢失后，开发者无法替你恢复未备份的数据。

CSV 导出：导出的 CSV 是明文，可能包含金额、账户名称、成员、备注和标签。持有文件的人可能读取其中内容。请在分享前确认文件内容和接收方，勿把 CSV 当作加密备份。

系统文件选择器可能显示你自己的 iCloud Drive 或其他云盘；分享面板也可能包含第三方应用。你主动选择这些目标后，文件可能由该服务上传或处理，适用该服务的隐私政策。应用不自行上传，也不自动同步这些文件。

恢复时先检查文件有效性，确认后才替换本机账本，并保留一份恢复前的本机快照供撤回。请在覆盖重要数据前保留自己确认可用的备份。

05. 查看、更正与删除

你可以在应用中查看和编辑账单、管理账本与分类、导出记录或创建加密备份。为了保留账务关联，某些删除操作需要先处理关联账单或取出目标中已分配的资金。

在“我的”中的清空操作，经确认后可删除应用本机账本数据和设置。已导出到“文件”、云盘、其他应用或分享给他人的副本不会同时删除，需要你在对应位置另行处理。应用不会删除照片图库中的原始照片。

我们没有可供查询或删除的开发者端账本副本。不要为请求删除而向公开反馈渠道发送账单、身份证明、备份文件或密码。

06. 本网站与公开反馈是独立的场景

这个介绍网站使用 GitHub Pages 托管。网站本身不添加分析追踪脚本、广告、第三方字体、外部图片或 CDN 依赖；主题预览只在当前页面内切换，不建立账号、不保存账本数据。

访问网站时，托管服务 GitHub 可能为提供服务、运维及安全处理标准访问日志，例如 IP 地址、请求时间、设备或浏览器信息。具体处理以 GitHub 隐私声明为准。这不意味着离线应用向 GitHub 上传账单。

支持反馈通过 GitHub Issues提供。你在该平台发布的账户名、问题描述、评论与附件可能公开可见，开发者可查看你主动提交的内容。请仅提供不含个人信息的复现步骤，不要上传真实账单、账户号码、备份、密码或未打码截图。使用 GitHub 本身适用其条款与隐私政策。

07. 政策变更与联系

如果应用的数据处理方式发生变化，我们会更新本页的内容与日期，并在适当位置说明。当前政策仅描述本版应用与本网站的实际行为。
